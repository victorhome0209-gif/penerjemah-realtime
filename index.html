Baris 1

Dialog sendiri

Satu baris per kalimat. Awali dengan Saya: (dibacakan dalam Indonesia) atau Lawan: (dibacakan dalam Inggris). Tambahkan acuan terjemahan setelah tanda |. Tanpa awalan, baris bergantian Saya dan Lawan. Contoh:
Saya: Halo, apa kabar? | Hello, how are you?

Akses backend (uji)

VocalBridge hanya bekerja lewat layanan AI di server (OpenAI untuk pengenal suara, terjemahan, dan suara). Isi alamat server dan kode akses dari administrator. Tanpa itu, penerjemahan tidak berjalan dan tidak ada mesin cadangan.

Layanan AI belum terhubung.

Jangan mengisi API key OpenAI atau penyedia lain di sini. Kunci penyedia hanya ada di server. Kode akses disimpan untuk tab ini saja dan hilang saat tab ditutup.

Cara kerja: ucapan dikirim lewat server VocalBridge ke OpenAI untuk diubah menjadi teks, diterjemahkan, dan dibacakan. VocalBridge tidak menyimpan audio. Kebijakan OpenAI berlaku untuk data yang diterimanya.

Sebelum mulai

  • Mikrofon (dan audio tab bila Anda memilihnya) dipakai hanya selama sesi berjalan. Tombol Hentikan melepasnya.
  • Ucapan dikirim lewat server VocalBridge ke OpenAI untuk jadi teks, terjemahan, dan suara. VocalBridge tidak menyimpan audio. Kebijakan OpenAI berlaku untuk data yang diterimanya.
  • Suara terjemahan dari OpenAI dibuat oleh AI, bukan suara manusia.
  • Riwayat teks tersimpan di perangkat hanya bila Anda menyalakannya. Audio tidak pernah disimpan.
  • Anda yang memberi tahu lawan bicara dan memastikan penggunaan sesuai aturan platform (Zoom, Meet, Upwork).
  • Terjemahan mesin bisa salah. Periksa angka, nama, dan tanggal penting secara tertulis.
