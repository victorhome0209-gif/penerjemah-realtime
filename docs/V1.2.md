# VocalBridge V1.2: hanya OpenAI lewat backend (tanpa mode Gratis)

Keputusan produk: VocalBridge adalah alat komunikasi dua arah yang mengandalkan OpenAI API. Tidak ada mode Gratis.

## Audit sebelum mengubah (apa yang bergantung pada mode Gratis)
| Bagian | Bergantung pada Gratis? | Tindakan |
|---|---|---|
| Pengenal suara browser (`SR`, `buildRec`, `startFreeListen`, `onFreeThem/Me`) | Ya, khusus Gratis | Dihapus |
| Terjemahan MyMemory (`translateFree`) | Ya | Dihapus; `translate()` menolak bila layanan belum terhubung |
| Suara perangkat (`speak`, `speechSynthesis`) dipakai sebagai cadangan TTS di `speakSmart`, `replay`, `speakFor` | Ya | Dihapus; TTS hanya dari backend, gagal ditampilkan apa adanya |
| Label/lencana "Gratis", teks pengaturan, teks privasi | Ya | Diganti "Belum terhubung" / teks baru |
| `Conv.free` pada mesin status percakapan | Ya | Dihapus |
| QA Lab (naskah, WER, diff, ekspor, ulasan) | Tidak | Utuh. Hanya tombol rekam yang butuh layanan |
| Tes mikrofon dan pengaturan mikrofon (`Capture`) | Tidak | Utuh, berjalan lokal tanpa layanan |
| VAD, satu tombol, giliran bicara, anti-echo (`speaking`, `cool`, jeda lawan) | Tidak | Utuh |

## Perilaku baru
- Tanpa alamat server/kode akses: layar utama menampilkan **"Layanan AI belum terhubung."**; tombol Saya Bicara tidak membuka mikrofon dan tidak memulai sesi.
- Sebelum persetujuan dan mikrofon, sesi memeriksa layanan lewat `GET /api/me` (tanpa biaya, satu percobaan, batas 7 detik). Gagal karena server tidak terjangkau, kode salah (kode dihapus dari tab), atau layanan dinonaktifkan administrator: pesan diawali "Layanan AI belum terhubung." dengan alasannya, sesi tidak dimulai.
- Kegagalan di tengah sesi ditampilkan di kartu ("Gagal menerjemahkan", "Suara gagal"); tidak pernah beralih ke jalur gratis dan tidak ada teks terjemahan palsu.
- Tidak berubah: satu tombol, lawan didengar otomatis, empat teks, anti-benturan STT dan echo, autentikasi, kredit, anggaran, transaksi UNKNOWN. Backend tidak diubah.

## Hasil uji aktual (lokal, `node tests/run-all.js`, exit 0)
Backend 95/95, statis 31/31, dependensi 17/17, regresi QA Lab 20/20, E2E Chromium 125/125. Uji mutasi: dengan `index.html` lama, 7 pemeriksaan statis dan 10+ pemeriksaan E2E baru GAGAL, jadi tes benar-benar menangkap perilaku lama.

## Perubahan yang disengaja pada tes
- `tests/regress.js`: fungsi `speak` boleh hilang (suara perangkat sengaja dihapus).
- `tests/e2e/run.js`: tes "Mode Gratis" diganti lima tes V1.2; tes "Dinonaktifkan admin" kini memeriksa bahwa sesi tidak dimulai.

## Risiko tersisa
1. Belum ada uji OpenAI nyata (tidak diizinkan); semua uji memakai OpenAI palsu.
2. Tanpa internet/backend aplikasi tidak berguna sama sekali (disengaja).
3. Biaya: tiap ucapan = STT + terjemahan + TTS; batas anggaran harus diset juga di dashboard OpenAI.
4. Model TTS `gpt-4o-mini-tts` berhenti 2027-01-06.
5. Hanya Chromium yang diuji; Safari/Firefox/HP nyata belum.
6. Pemeriksaan `GET /api/me` menambah satu permintaan kecil saat memulai sesi.
